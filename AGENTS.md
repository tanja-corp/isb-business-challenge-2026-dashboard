# HTML Dashboard Publishing

- The GitHub Pages source of truth is `ISB_BC2026_dashboard.html`, the latest Japanese dashboard.
- The Pages workflow publishes that file at the site root as `index.html`.
- When the user asks to update the HTML dashboard, update this Japanese source and push the finished change to `main` so GitHub Pages redeploys. The user explicitly authorized commits and pushes without asking again.
- Check the deployment workflow and the live page after pushing, then share the Pages URL.
- Keep this repository limited to the Japanese dashboard and the files needed to publish it. Do not add the English dashboard or the surrounding project notes and drafts.
